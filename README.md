# OSRS QoL Plugins

Experimental RuneLite plugin projects:

- **Milestone Screenshots:** captures levels 20, 40, 60, 80 and 99 (configurable).
- **Combat Coach:** suggests combat training targets based on combat skills and unlocks, and places a world-map marker.

## Jagex Account compatibility

Jagex Accounts require the official login flow through the **Jagex Launcher**. Standalone RuneLite development clients are not a suitable sign-in test for these accounts. Do not provide Jagex credentials to third-party login tools.

**Goal:** publish reviewed plugins to the official [RuneLite Plugin Hub](https://github.com/runelite/plugin-hub), then install them into normal RuneLite opened by Jagex Launcher. Merely uploading the code to GitHub does **not** install it into RuneLite, and Plugin Hub approval is not guaranteed.

## Current state

**Unreleased prototypes.** Compilation and real account gameplay have not been validated for the combined build. Combat advice is curated and does not establish maximum XP/hour. The source project can be uploaded from the local `OSRS-Combined-Plugins` folder.
